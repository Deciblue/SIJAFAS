# SIJAFAS - Smart Facility Management System

## Overview
SIJAFAS is a campus facility maintenance system that digitizes reporting, scheduling, and repair workflow in real-time.

## Problem
Manual facility management causes delays, no tracking, and no transparency.

## Solution
A centralized system connecting:
- Students
- Lecturers
- Admin Sarpras
- Head Sarpras
- Technicians

---

## Tech Stack
- Laravel 12 (API + Blade)
- MySQL 8
- Flutter (Mobile App)
- Firebase (Auth + Notification)
- Sanctum (API Security)

---

## Core Workflow
1. User reports damage
2. Admin validates report
3. Work order created
4. Schedule approval by head sarpras
5. Technician assigned
6. Execution + evidence upload
7. Completion verification
8. Audit log stored

---

## System Modules
- Damage Reporting
- Work Order System
- Scheduling Engine
- Technician Task Execution
